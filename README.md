# Crue

Headless storefront for Crue, a high-end running brand. Shopify is the system of record for catalog, cart, checkout, orders, content, and the merchant admin. This repo is the website.

## Start here

Read [`docs/README.md`](docs/README.md) before changing the product. Docs hold the what and why. Code holds the how.

## Workflow

- `/req` drafts a requirement under `docs/requirements/`. It does not write product code.
- `/audit` checks a requirement for missing edge cases and conflicts with the docs.
- `/build` implements one accepted requirement and its Jest tests. It does not start from a draft.

No storefront code exists yet. The first feature waits for an accepted requirement.
