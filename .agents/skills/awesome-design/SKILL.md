# Awesome DESIGN.md

The catalog is https://github.com/voltagent/awesome-design-md. It is a set of third-party `DESIGN.md` files. It is not Crue's design system.

## When this runs

1. Read `docs/design-language.md` and the accepted requirement first.
2. Fetch only the brand the user names. Do not browse the catalog and pick one.
3. Use the reference for restraint, spacing, and editing. Do not copy its colors, type, logo, or layout into Crue.
4. If the reference and `docs/design-language.md` disagree, the Crue doc wins.
5. Do not add a third-party `DESIGN.md` to the repo unless the user asks for that file by name.

## Do not

- Treat Nike, Shopify, Vercel, or any other file in the catalog as Crue's tokens.
- Invent a Crue palette from a reference brand.
- Replace `docs/design-language.md`.
